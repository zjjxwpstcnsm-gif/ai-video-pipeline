# AI Video Pipeline

Public software tools for a private-data-aware video production workflow.

This repository has independent Git history. Private media, character references,
creative prompts, production projects, credentials and generation results must not
be committed here, printed in public Actions logs, or uploaded as public artifacts.

The reusable engine and privacy-guarded workflows are being migrated separately.
Until migration and credential validation finish, retain the existing private
production entry points. Creating this repository does not authorize public access
to the source data or enable production rendering.
